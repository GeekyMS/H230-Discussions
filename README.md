# H230 Discussions

Weekly discussion write-ups for COMPSCI H230, built around **MiniOS**, a
userspace process-management and scheduling system written in Rust.

Each week's work is snapshotted into its own folder here, alongside a
README explaining what was implemented and observed. Later weeks that
involve quantitative experiments (e.g. scheduling parameter sweeps)
include a `results/` folder with CSV data, a Python generation script,
and the resulting plots.

The full, continuously-developed MiniOS project lives in a private
repository; this repo holds public, per-topic snapshots for discussion.
